# Plöttr v2.1.0 "Tidy Up" — release notes

A tidy-up after the 2.0 redesign: rows reorder by dragging, Group Plot loses a step it no longer
needed, the folded statistics column is easier to spot, and exported SVGs open in Inkscape with
every element named. Charts and statistical results are unchanged.

## ✨ Added

### Drag and drop to reorder

Every list that reorders with ↑ / ↓ — Group Plot's value lists on the filter step, the group and
outcome lists in Proportions, and the group order in qPCR — now also reorders by dragging a row by
the ⋮⋮ grip on its left. While dragging, the row fades and a line shows where it will land;
dropping it back in place changes nothing. Values merged under one name in Group Plot move
together, as they do with the arrows, and long lists scroll when the pointer nears their edge.
The arrows stay as the keyboard path. Dragging uses pointer events, so it works with touch too
and the rename fields keep normal text selection.

## 🔧 Changed

### Group Plot: no more Output step

Group Plot now runs Upload → Configure → Filter → Plot. The Output step only offered two
downloads, which now sit in the plot step's "More" menu:

- **Long CSV** — the filtered and renamed data, one row per observation, always one file: every
  row keeps its facet and subgroup columns, so nothing is lost.
- **Wide CSV** — one column per group. That layout drops every other column, so with facets or
  subgroups it is split into one file per facet × subgroup, named after them
  (`<file>_<facet>_<subgroup>_wide.csv`). More than three files arrive as one `.zip`, as for any
  multi-file download.

The summary table the step showed is in the Statistics column.

### Statistics strip is easier to find

The folded "Statistics" strip on the right of the plot now shows its label as a blue button, the
colour Plöttr uses for actions, so the hidden statistics column is harder to miss.

## 🐛 Fixed

### SVG exports: every element in a named group

Exported SVGs are meant to be reopened in Inkscape, where elements are picked by name. An audit of
every tool's export found a few gaps, now closed:

- **qPCR** drew its brackets and letters once per gene under the same id, which Inkscape silently
  renames. They are now `significance-brackets-<gene>` and `cld-annotations-<gene>`.
- **Heatmap** exported an unnamed pointer-capture rectangle; it and the hover / drag-selection
  highlights are now `interaction-overlay`, `hover-highlight` and `brush`.
- **Group Plot** composition pies are named `composition-<group>`.
- **Venn, Group Plot, Line Plot and RLU Timecourse** backgrounds are named groups, like every
  other chart's.

The figures look exactly as before. A new end-to-end test downloads every tool's SVG and fails on
an unnamed element, a duplicate id or a loose top-level element.
