# Plöttr v1.11.0 "By the Book" — release notes

Two new tools for data that doesn't belong on a t-test (counted outcomes and qPCR Ct values),
a ready-to-copy Methods paragraph in every stats panel, and a statistics pass that brings
Plöttr's numbers in line with R's defaults. Large files, decimal commas and very large x values
no longer break things silently.

## ✨ Added

### Proportions & counts tool

For counted outcomes (% germination, % colonised plants, phenotype classes), where a t-test on
percentages is the wrong test. Paste a counts table (one row per group, one column per outcome)
to get:

- % per group with Wilson 95 % confidence intervals;
- proportion, stacked or mosaic bars;
- Fisher's exact test or χ², chosen by the 2×2 rule and Cochran's rule (overridable; χ² on small
  expected counts is flagged), with the expected counts shown in the explanation;
- Holm-corrected pairwise Fisher tests, with a short explainer contrasting Holm (family-wise)
  with Benjamini–Hochberg (FDR);
- goodness of fit to expected ratios such as 3:1 or 9:3:3:1.

Exports: CSV, a stats report and an R script. The new kernel `tools/_core/stats/categorical.ts`
(`wilsonCI`, `binomTest`, `chiSquareIndependence`, `chiSquareGOF`, `multinomialExactGOF`,
`fisherExact` with network enumeration and a seeded Monte-Carlo fallback, `holmAdjust`,
`pairwiseFisher`, `selectCountsTest`) is pinned to R in the tests and in 69 new benchmark
comparisons.

### qPCR relative expression tool

Paste raw Ct values, in long or wide layout, to get relative expression per biological sample:

- **2^−ΔΔCt** (Livak & Schmittgen 2001) or **efficiency-corrected ratios** (Pfaffl 2001);
- **several reference genes** combined by geometric mean (Vandesompele et al. 2002);
- **"Reference genes only"** normalisation, which plots 2^−ΔCt with no calibrator group
  (Schmittgen & Livak 2008);
- efficiencies typed in or estimated from a standard curve;
- QC for undetermined wells, noisy technical replicates and reference-gene stability (geNorm M).

Statistics run on ΔCt with the Group Plot engine (Welch t / Welch ANOVA + Games-Howell, with an
override and the decision trace). They never run on fold changes. Error bars can be SEM, SD,
95 % CI or none, all computed on the log2 scale. A "Calibrator column" switch hides the
control's bar, which is always 1: its comparisons become "vs control" stars above each bar,
with a footnote.

Display options in the tool itself: bar, dot or box plots, horizontal orientation, a fixed
value range shared by every gene panel (typed in the axis-label units), an editable axis title,
point size and spread, and fill opacity. On the linear fold-change axis, bars start at 0 and
the FC = 1 line stays. The log axis has a tick at every doubling.

Exports: TXT report and an R script that recomputes ΔCt from the raw Ct. Maths pinned to R in
`tests/qpcr.test.js`, invariants in `tests/qpcr.property.test.js`, plus `e2e/qpcr.spec.ts`.

### Methods text

A "📝 Methods" button in every stats panel (Group Plot, RLU, Line Plot, qPCR, Scatter,
Proportions, UpSet) and on the Heatmap. It opens a read-only paragraph with a Copy button,
ready for a paper's methods section. It covers the tests that actually ran (with exact or
approximate p), post-hoc tests, corrections, sample sizes, what the chart shows, the Plöttr
version and URL, and the equivalent R calls. Those calls come from the same builders as the R
export (`rTestCall` / `rPostHocCall`), so the two always agree. English and French. No
references are added: the user cites what their journal expects.

### Heatmap colour-scale tools

- **Outlier-skew alert.** When a few cells (≤ 2 %) stretch the colour scale so that the rest of
  the matrix uses less than half of it, a warning offers to exclude exactly those outliers: the
  range becomes the extent of the other cells, rounded outward. Clipped colourbar ends read
  "≥ max (n=…)" / "≤ min (n=…)", which survives SVG/PNG export. The R export clusters on the
  unclipped values, then clips, so pheatmap paints out-of-range cells with the end colours
  instead of grey. The sample dataset gains three outlier spikes to show this.
- **Colour-range histogram.** The Colour scale section shows the value distribution (outliers in
  a broken-axis stub) with draggable Min / Max handles, live clipped counts and Full /
  Outliers / 1–99 % / 5–95 % presets. "Full" replaces "Auto from data". The distribution can
  also be drawn beside the figure's colourbar ("Distribution in legend"), with a caption giving
  the longest bar's cell count so the exported figure explains itself.

### Smaller additions

- **Example input tables in the How-to** for Proportions (counts table) and qPCR (long and wide
  layouts), via a shared `HowToExampleTable`.
- **Proportions:** a group-label angle slider (−90…0°), matched in the R export; the stats panel
  gets a "Statistics" header with its TXT / R downloads.
- **Chart-style icon picker** (bar / dot / box) shared by qPCR and Group Plot.

## 🔧 Changed

### Statistics now follow R's defaults

The goal of this pass: for the same data, Plöttr reports the number R reports with its default
arguments. Where R itself is inaccurate, Plöttr departs from R only toward the exact value, and
says so here.

- **Exact p-values for rank tests on small samples.** Mann-Whitney (both n < 50), Spearman
  (n ≤ 1290) and Kendall (n < 50) without ties now give the exact p that `wilcox.test` /
  `cor.test` report by default. These are ports of R's C sources (`pwilcox`, AS 89 `prho`,
  `pkendall`). Before, Plöttr always used the normal / t approximation, which can be off by a
  factor of 2 at n ≤ 6. With ties, the approximation is kept, as in R. The R-script exports and
  the benchmark drop `exact = FALSE`.
- **Correlation power** is a port of `pwr::pwr.r.test` (agreement to 1.5e-13). The previous
  plain Fisher-z approximation was off by up to ~20 power points at n ≤ 8.
- **Welch effect size** is now `effectsize::cohens_d(pooled_sd = FALSE)`: √((s₁² + s₂²)/2) with
  a Welch-df CI, instead of d_av ((s₁ + s₂)/2) with a pooled-df CI. An old code comment claimed
  this R call returns Glass's Δ. It doesn't, and the comment is gone.
- **Normal distribution** (`normcdf` / `normsf`) ports R's `pnorm` (Cody's algorithm). The
  previous Abramowitz & Stegun 26.2.17 formula had absolute error up to 7.5e-8, which is 0.15 %
  relative error in Spearman's Edgeworth tail at n = 12. z-based p-values and power now match
  R to ~1e-15.
- **Noncentral t** (`nctcdf`) ports R's `pnt`. For |δ| > 37.62 and the far lower tail it uses a
  panelled integral instead, because R's own `pt` is rough there: `pt(10, 1, 50)` gives 1.3e-9
  against a true 6.5e-7. Cohen's d CIs therefore stay exact at very large effects (they drifted
  up to 3 % at d ≥ 12). At d = 182 the CI follows SciPy's exact value, not `effectsize`'s.

### Heatmap diverging palettes keep their neutral colour at 0

Each side of 0 now gets its own colour slope (a two-slope map), so Min and Max can be set
independently (e.g. −2 … +8, or 0 … 8) and 0 always keeps the white/grey midpoint. This holds
for every range, including ranges that start at 0 or exclude it. The colourbar marks 0, and the
R export computes each colour bin with the same rule. Lopsided ranges on diverging palettes
render differently from before.

### Layout

- **One export bar, in the same place in every tool.** On the plot step the page header is slim
  and stays pinned while you scroll: a one-line step breadcrumb, then every download (SVG / PNG
  / CSV / R …) and Start over, which now asks for a second click. Each tool's actions panel
  registers its downloads through a shared `PlotActionsContext`. Heatmap's SVG / PNG buttons
  moved there from the plot card. Stats-panel reports stay in their panel.
- **Charts display at their true size**, shrinking only when the window is narrower, so text
  sizes match across tools. Proportions and qPCR tick labels default to 11 like the rest.
- **Stats panels lead with the result.** The result line comes first, in bold. The "why this
  test" reasoning folds into a "Why this test?" disclosure.

## 🐛 Fixed

- **Large files no longer fail silently.** `Math.min(...arr)` / `Math.max(...arr)` on data-sized
  arrays hit the JavaScript argument limit past ~125,000 values, so uploads did nothing in Group
  Plot, Proportions, qPCR and other tools. They now use `arrayMin` / `arrayMax`
  (`_core/numeric.ts`). Checked in Chromium with a 180k-row file. Regression: 6 tests.
- **Calculators accept decimal commas.** Molarity read "1,5" as 1. Every Molarity field now goes
  through `parseDecimal`. Power's free-text list fields (group means, proportions) accept
  "10,5; 12; 15", with semicolons between values when decimals use commas. Power's α and power
  are preset buttons, so they were never affected.
- **Scatter regression line for large x.** The slope used uncentred sums, which lose precision
  from x ≈ 10⁷ (genomic positions, timestamps). A two-pass centred fit now matches R's `lm` to 12
  digits at x = 1.7e9.
- **Heatmap clustering with missing cells.** Euclidean and Manhattan distances are rescaled for
  the missing pairs like R's `dist()`, so rows with gaps no longer look closer than they are. The
  correlation R export uses `pairwise.complete.obs`.
- **A stray opening quote** (e.g. `"Col-0`) is read literally instead of swallowing the rest of
  the CSV into one cell.
- **Axis ticks** are index-based and capped, so values ≳ 10¹⁶ with a small range no longer hang
  the tab.
- **Kendall τ on large data** uses Knight's O(n log n) method: 100k points take ~0.1 s instead of
  ~35 s.
- **Imported settings files** must give hex colours and known palette names. Free-form option
  strings still rely on each renderer's fallback.
- **Sidebars no longer open scrolled down.** Sections that start expanded scrolled the sidebar on
  load, hiding its top (e.g. Group Plot's downloads). Heatmap's sidebar is now sticky too.
- **Heatmap:** the palette menu uses the app's dropdown style; the outlier warning shows once
  (above the plot) instead of twice; data at subnormal scale no longer drops cells from the
  histogram.

## 🧰 Internal

- `npm run benchmark` works again: `run-r-export.js` and `run-scipy.js` bundle the current
  TypeScript sources with esbuild instead of reading the removed `tools/stats-*.js` files.
- Group Plot's role / facet / subgroup hand-off support (`resolveHandoffLayout`) was removed with
  the qPCR "Send to Group Plot" button, its only user.
- New `release.yml` workflow: pushing a `v*` tag now creates the GitHub Release from
  `docs/release-notes/<tag>.md`.

Unchanged on purpose: the Aequorin Lmax denominator stays a faithful translation of the lab's
method. The full audit is in
