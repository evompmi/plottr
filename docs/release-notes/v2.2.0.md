# Plöttr v2.2.0 "Clean Wells" — release notes

qPCR gets a fill-in Excel template and a say over noisy technical replicates. Around it, a round
of interface polish: the coloured mapping and column-role boxes become plain panels, and a few
small controls behave the way their neighbours do. Charts and statistical results are unchanged
unless you choose to drop wells.

## ✨ Added

### qPCR: fill-in Excel template

The upload step offers an Excel template (.xlsx), built in the browser in English or French. It
has three sheets:

- **How to fill** — what each column means.
- **Data** — empty, with the headers ready.
- **Example** — a small dataset that pastes straight into the tool.

The workbook is written by Plöttr's own dependency-free `.xlsx` writer, so nothing is fetched and
nothing leaves the browser.

### qPCR: keep or drop flagged technical replicates

A technical-replicate set whose Ct values spread by more than 0.5 cycles (SD) was already flagged.
Each flagged set now has a selector in Configure's Quality checks:

- **Keep all wells** — the default; nothing is excluded automatically.
- **Drop the outlier well** — the well farthest from the set's median. Offered only for sets of
  three or more wells with a single clear outlier.
- **Drop the whole set.**

Exclusions flow into everything downstream: the statistics, the report, the R script (which
receives only the kept wells) and the Methods text. A set stays listed after you exclude from it,
so the choice can be undone.

## 🔧 Changed

### Plainer mapping and column-role boxes

The coloured boxes with tinted header bands are gone.

- **Scatter and Volcano sidebars** — the Colour / Size / Shape mapping boxes are ordinary sidebar
  sections, like Point style or Thresholds. Each has a small glyph for its aesthetic and, once a
  column is mapped, a tag naming the detected column type ("continuous", "3 categories").
- **Configure step (Group Plot, Line Plot, RLU Timecourse, Volcano)** — the column-role cards
  (Group / Value, X / Y / Group by, Calibration / Time axis, X / Y / Label) are white panels with
  the same small section title, matching the "Other columns" and data-preview panels below them.

### Smaller fixes to controls

- **Heatmap** — the cell-border width is a −/+ number box like the other numeric settings, and
  the border colour has its own title, aligned with Width.
- **Venn** — clicking the selected row of the Intersections list again clears the selection, as
  clicking a selected region on the chart already did. The Items hint says so.
- **RLU Timecourse** — Sample selection sits on its own row under Series / Layout, and its panel
  opens in place, pushing the plot down instead of floating over it.
- **Landing** — the rule above the four "how it works" steps is gone and the steps sit a little
  higher.
