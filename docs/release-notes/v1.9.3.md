# Plöttr v1.9.3 "Dash & Dot" — release notes

A Line Plot styling release, with one stats-panel correctness fix that shipped
alongside it. Every group in a Line Plot chart can now carry its own line
style and point marker — not just its colour — so a printed or colourblind-
unfriendly figure can still tell series apart. Group Plot's compact-letter
labels also got a quiet fix: a condition with no data no longer pushes every
significance letter one box out of place.

## ✨ Added

### Per-group line style and point shape in Line Plot

Each group's row in the Groups sidebar section gained two pickers next to the
existing colour swatch:

- **Line style** — solid / dashed / dotted, with the dash pattern scaled to
  the current line-width setting so it stays proportional at any thickness.
- **Point shape** — circle / square / triangle / diamond, plus a filled/open
  toggle button that previews the current shape and colour.

The legend and the exported SVG/PNG both reflect the chosen style, so a
figure pasted into a manuscript or printed in grayscale keeps every series
distinguishable by line pattern and marker shape, not colour alone.

Under the hood, `computeSeries` (`tools/lineplot/helpers.ts`) now resolves
per-group style from three new `vis` maps (`groupLineStyles`,
`groupPointShapes`, `groupPointFilled`), mirroring the existing
`groupColors` pattern. The shared SVG-legend renderer
(`tools/_shell/svg-legend.ts`) picked up a `diamond` shape and an
open/filled marker variant as part of this — additive changes only used by
Line Plot today, but available to any tool that wants them later.

## 🐛 Fixed

### Group Plot: CLD letters / brackets misaligned when a condition has no data

When one or more conditions in a Group Plot chart have fewer than two
values, they're excluded from the significance test (correctly — there's
nothing to test) but are still drawn as empty boxes on the chart. The
compact-letter-display labels and post-hoc brackets were built from indices
over only the _tested_ conditions, while the chart positions annotations
across _all_ displayed conditions. An untested condition sitting in the
middle of the axis shifted every letter and bracket one box to the left of
where it belonged.

The stats panel now also computes the full displayed-group ordering and a
valid→displayed index map, and the annotation builder projects labels and
bracket indices through that map — leaving the untested condition's slot
blank instead of borrowing its neighbour's letter.
