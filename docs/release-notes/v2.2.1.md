# Plöttr v2.2.1 "Quick Spin" — release notes

A speed release. Three tools that stalled on large files now respond quickly. Every chart,
statistic, dendrogram and label position is exactly the same as in v2.2.0; only the time taken
changes.

## 🔧 Changed

### Faster on large files, with identical results

Measured on files near the size limits:

| Where                                         | v2.2.0 | v2.2.1 |
| --------------------------------------------- | -----: | -----: |
| Line Plot, opening the plot (200 x-values)    |  5.8 s | 0.34 s |
| Heatmap, opening the plot (2 000 rows)        |  2.7 s |  0.5 s |
| Volcano, moving a label slider (30 000 genes) |  2.9 s |  0.1 s |
| Volcano, opening the plot (30 000 genes)      |  0.5 s | 0.16 s |

- **Line Plot** — the replication-planning figure (the n per group needed for 80% power) was found
  by trying every n from 2 to 5 000, for every x-value, as soon as the plot opened. Power only
  rises with n, so a binary search now finds the same n in about a dozen steps. It also runs only
  for the x row you expand, and for the downloaded report, instead of for all rows up front.
- **Heatmap** — row and column clustering remembers each cluster's nearest neighbour instead of
  re-comparing every pair after each merge. Ties are broken in the same order as before, so the
  dendrograms are unchanged.
- **Volcano** — label placement looks up only the points near each candidate label position,
  using a grid, instead of checking every point on the plot.

Each change is covered by tests that compare the new method against the old one, including on
data with ties, missing values and infinite values. Regression: 11 tests.
