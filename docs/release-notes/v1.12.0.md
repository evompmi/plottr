# Plöttr v1.12.0 "Hand in Hand" — release notes

Group Plot and Proportions now work hand in hand: the composition pies in Group Plot can be sent
straight to Proportions for a counts test, and Proportions can compare every group with one
control. Group Plot's boxes gain a little styling, and data sent from one tool to another now
always lands where you clicked.

## ✨ Added

### Composition pies → Proportions

With composition pies on (Group Plot → a "Color by" column), Group Plot can send the pie counts
to Proportions for a Fisher or χ² test. The counts are the number of observations of each
colour-by class in each group: exactly what the pies draw, in the same order and with your group
renames.

- Facets are never pooled: each facet becomes its own counts table.
- Groups are labelled `facet.subgroup.group`, so a subgrouped or faceted plot stays readable in
  Proportions.

### Proportions: compare with a control

Pairwise comparisons can now test each group against one chosen control group only, instead of
every pair. With k groups this runs k − 1 Fisher tests and adjusts the p-values over those
k − 1 tests, so the correction is less severe than over all pairs. The stats report, R script and
Methods paragraph describe the comparison that actually ran. The results match R's
`fisher.test` followed by `p.adjust`.

### Group Plot: box styling

Two new settings under **Shape & fill** for the box, violin and raincloud styles:

- **Box corners:** rounded (the default, unchanged) or square.
- **Outline & median:** the group colour (the default) or a custom colour, black by default.
  The custom colour draws the box border, the median line and the violin edge; the fill keeps
  the group colour.

Both settings are saved with your plot preferences and in preference files.

## 🐛 Fixed

### Inter-tool hand-off

Sending data from one tool to another (RLU timecourse → Group Plot, Group Plot → Proportions,
Venn → UpSet) is now more reliable:

- A tool that was already open no longer deletes a hand-off meant for a different tool.
- A hand-off that nobody picks up expires after 30 seconds instead of lingering.
- With Plöttr open in two browser tabs, the data now always lands in the tab you clicked in.
  Before, a copy of the target tool open in the other tab could grab it.

Under the hood, all three routes now share one receiver (`useHandoff` in `tools/_shell/`), and
hand-offs are kept per tab (`sessionStorage`) rather than shared across tabs.
