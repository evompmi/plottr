# Plöttr v2.3.0 "Consistency" — release notes

The tools now behave alike. A global interface review brought every tool onto the same controls:
checkboxes for on / off settings, one test picker, the same Configure layout. Proportions also
reads one row per observation, and Proportions, qPCR and Line Plot can print their statistics
summary under the plot. Statistical results are unchanged.

## ✨ Added

### Proportions reads one row per observation

Proportions used to accept only a counts table (groups × outcomes). It now also reads a file with
one row per plant, seed or animal, and counts the rows itself.

- **Detection.** A file that reads as a counts table is used as before. Any other file with at
  least two columns is read one row per observation.
- **Columns.** In Configure, three cards pick the group column, the outcome column and an
  optional column that already holds counts (one row per group × outcome, for example
  `Genotype, Status, n`). They start from a guess: an ID column, unique on every row, is skipped,
  and the outcome is the last text column.
- **Layout switch.** When a file could be read either way, "Counts table / One row per
  observation" picks the layout.
- **Skipped rows.** Rows with a blank group or outcome, or a count that is not a whole number ≥ 0,
  are left out and counted in a note.

The How-to shows the new layout with an example.

### Statistics summary under the plot in Proportions, qPCR and Line Plot

"Print summary below plot", already in Group Plot, is now in the toolbar of three more tools. The
grey lines are part of the SVG, so they are kept in the exported figure.

- **Proportions:** the test, the comparisons (all pairs, or each group vs the control), the
  multiple-testing correction and the Wilson CI.
- **qPCR:** Group Plot's lines for the ΔCt tests (normality, equal variance, test, post-hoc,
  error bars), one block under each gene's panel.
- **Line Plot:** the test run at each x, the Benjamini–Hochberg step across x and the error bars.
  Line Plot also gains Group Plot's "Show ns".

The drawing is shared with Group Plot (`_shell/StatsSummary.tsx`); Group Plot's figure is
unchanged.

## 🔧 Changed

### One set of controls across tools

- **On / off settings are checkboxes** in every tool (about 30 of them, through one shared
  `CheckboxField`). Segmented buttons are kept for choices between named options, such as
  Vertical / Horizontal.
- **One test picker.** Group Plot, Scatter, qPCR and Proportions use the same dropdown, with
  "(recommended)" on the default test; picking it clears an override.
- **Configure steps** in qPCR and Proportions use column cards like the other tools, with the
  file line above the data preview.
- **RLU Timecourse** draws its plot straight on the canvas instead of inside a fold-out panel.
- **Icons instead of emoji**: a line icon on the Methods button, a plain "Sample selection"
  button in RLU Timecourse, and text instead of 👁 to mark colour-blind-safe palettes (listed
  first in the discrete palette lists).
- **Volcano** axis titles, title and subtitle are sans-serif like every other chart. Gene labels
  stay monospace: the label layout sizes them as fixed-width text to keep them apart.
- **Calculators** share one page width, and their result numbers and section labels are plain
  text: blue marks only actions and links.
- **Line Plot and RLU legends** sit closer together for short labels.

## 🐛 Fixed

- **qPCR could get stuck on Configure.** A group unticked under "Reference genes only" and then
  made the control again stayed unticked behind a locked checkbox, so the plot step stayed
  disabled with no way out. The control now always counts, and Configure lists what still blocks
  the plot: reference / target genes, too few groups, or an efficiency that is not valid.
- **The Methods popover stays on screen.** It opens above the button when the button is near the
  bottom of the window and is kept inside the window, so Copy is always reachable.
- **Statistics column.** Proportions and qPCR no longer repeat "Statistics" as their first
  section title, and table cells no longer break inside a value (Proportions shows the Wilson CI
  on its own line under each count).
- **Venn legend names are dark text** next to a set-coloured swatch; coloured text was hard to
  read in exported figures.
- **The landing page** lists the text file Group Plot actually downloads (`stats.txt`).
