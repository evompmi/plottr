statistical cross-validation vs R + SciPy

  • Two independent references. Plöttr's tools/_core/stats/*.ts is cross-checked against (a) R 4.5.3 on real built-in datasets and (b) SciPy 1.17.1 on synthetic targeted grids over the (df, λ) regimes the R bank only touches indirectly.
  • Plöttr reruns every function in tools/_core/stats/*.ts against its R 4.5.3 counterpart on real built-in datasets (iris, PlantGrowth, ToothGrowth, mtcars, chickwts, InsectSprays, sleep, women, trees, airquality, warpbreaks).
  • Inputs are bit-identical between R and Plöttr.
  • Tolerance by metric tier (calibrated to the observed agreement): |Δ| ≤ 1e-7 on test statistics and point estimates, ≤ 1e-5 on Cohen's d CIs, ≤ 1e-3 on Tukey HSD CI bounds. P-values: absolute 1e-5 above 0.01, log-space below (ratio within [1/1.1, 1.1]).
  • Post-hoc tests (Games-Howell, Dunn-BH) are validated against PMCMRplus, the canonical R package for non-parametric multiple comparisons. Brown-Forsythe Levene is validated against car::leveneTest(center = median), the canonical R reference for that test family.
  • R-floor rows (amber): R's ptukey saturates at ~2.2e-15 due to a 1 − ptukey(q) cancellation. Plöttr's ptukey_upper computes the survival directly and continues the true tail past that floor (cross-checked against scipy and Monte Carlo). These rows are not JS failures — R is simply no longer ground truth there.
  • SciPy benchmark. 1,083 comparisons across 9 categories specifically targeting the noncentral distributions (nctcdf, ncf_sf, ncchi2cdf) and qtukey at the (df, λ) corners the R bench can't reach. Tolerances calibrated to each routine's design envelope: 1e-6 relative for central distributions, 5 % relative for noncentral / qtukey, factor-of-1.5 log-space in the deep tail. Underflow / deep-tail / pathological rows are bucketed separately (see panel below).
  • Real failures are flagged in red and counted honestly.
  • Reproduce locally: Rscript benchmark/run-r.R && node benchmark/run.js && node benchmark/run-scipy.js
